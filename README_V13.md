# Horizonte V13 — Lapidação

Baseada na V12 estável/testada.

## Ajustes
- Filtros de lançamentos agora abrem em diálogo funcional.
- VR Flash: saldo atual + saldo inicial + receitas + despesas.
- VR Flash: limite diário recomendado até o próximo dia 20.
- VR Flash: editar/excluir movimentações diretamente no histórico.
- Metas: seleção entre metas individuais e grupos existentes ao agrupar.
- Metas: agrupar uma individual cria novo grupo; adicionar a grupo existente mantém o grupo.
- Metas: desagrupar continua permitindo inteira ou uma meta específica.
- Perfil: nome do usuário e nome do parceiro configuráveis.
- Metas individuais usam apenas o usuário do app; metas conjuntas permitem usuário/parceiro.
- Campos monetários novos começam vazios quando não há valor.
- Acesso rápido do Dashboard ganhou FGTS.
